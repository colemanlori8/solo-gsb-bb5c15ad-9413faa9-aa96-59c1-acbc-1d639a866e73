# 齿轮组选配 Web 应用（手摇机械装置试制辅助）

输入**目标输出转速比**、**允许相对误差**和 2～12 枚**带唯一编号与齿数的现有齿轮**，
系统在 **1～3 级传动**内穷举搜索（每级选一枚主动轮 + 一枚从动轮，一枚齿轮在整套方案中至多使用一次），
只返回误差达标的方案。

- 实际转速比以 **精确分数（BigInt）** 计算，无浮点误差
- 方案排序：**级数最少 → 相对误差最小 → 齿轮编号序列（自然字典序）**
- 无解时给出明确提示
- 展示每级配对（编号/齿数）、每级速比、总实际转速比（分数 + 小数）与相对误差

同时支持**批量装配**：一次为 2～3 台装置（各自目标速比与容差）分配同一齿轮清单，
每枚实物齿轮在整批中至多分配一次，并给出各台的选中配对、未满足状态与未用齿轮。

还支持**试制前缺齿补货**：给定 2 台装置、2～8 枚现有齿轮与 1～4 枚可购实物齿轮
（各有唯一编号、齿数、非负整数价格，合计不超 12 枚），枚举全部可购子集，
判断每个子集下两台能否在齿轮不复用时同时达标装配，并给出唯一采购建议
（购买枚数最少 → 总价最低 → 购买编号自然序）。

另支持**双档换速**：输入 4～12 枚齿轮与两个档位各自的目标速比、容差，
寻找**每档恰好两级**的达标装配——两档共用同一**有向齿轮对**作为固定第一级，
第二级按档换装（两档互斥运行，换装级可使用相同实物齿轮），
按“需更换轴位最少 → 两档相对误差之和最小 → 齿轮编号自然序”选出唯一方案。

还支持**带载安全选配**：沿用单台选配的齿轮、目标速比与容差规则，
另输入正整数**输入扭矩**与每枚齿轮的正整数**额定扭矩**（N·m）。
按无损传动逐级计算：每级主动轮承受该级输入扭矩，从动轮承受
“输入扭矩 × 从动齿数 / 主动齿数”（后者作为下一级输入）；两轮承受值均不得超过各自额定值。
**同一组配对的全部级次顺序分别校核**（扭矩随级次传递，级序不同载荷不同），
不用原搜索的规范化级序去重，也不以 300 条截断结果代替完整候选；
返回所有速比与载荷均达标方案的总数与前 300 条，无解时区分“速比无解”与“全部超载”。

另支持**轴位装配**：输入 **2～4 个沿一条直线依次排列的轴心整数坐标**
（一维写单个整数；二维写 `{x, y}`，全程整数精确判定共线与轴距）、统一正整数**模数**
与 **2～12 枚现有齿轮**及目标输出速比/容差。相邻轴之间各装一级传动，
中间轴上把前级从动轮与后级主动轮**同轴固定**（两枚不同实物），每枚齿轮全程只用一次；
每级必须满足安装距啮合条件 **2×轴距 = 模数×(主动齿数+从动齿数)**。
系统穷举每级满足轴距的全部**有向配对**（谁主动/谁从动都枚举）并跨级组合，
以精确分数校核总速比与相对误差，按“**相对误差最小 → 齿轮编号自然序**”选出最优方案，
返回达标方案总数与**逐轴安装明细**；无解时明确区分“**无可啮合装配**”
（几何上无整数齿数解，或配对跨级无法不重复）与“**可装配但速比不达标**”
（附误差最小的一种装配供参考）。

再支持**转速异常定位**：录入已装好的 **1～3 级**传动各级**主动 / 从动齿数**，
以及**多次观测**中各轴在**同一时段**的转数与每个读数的**绝对误差**
（真实转数 ∈ [读数−误差, 读数+误差]）；每次观测至少包含**输入轴与输出轴**，
允许缺少中间轴，同一观测内同一轴不得重复记录。系统按齿数精确计算理论速比，
把读数误差区间换算为任意两观测轴之间轴段的**实测速比区间**；在“**至多一级**存在
跨观测恒定倍率偏差（实测 = m × 理论）”的假设下，逐级求 m 的可行倍率区间
（含该级的轴段给出 m 约束并跨观测取交集，**不含该级的轴段用于交叉核对**）。
结论明确区分：**传动正常**、**可疑级位及其倍率范围**、**多个级位无法区分**、
**与单级恒定偏差假设不符**；只要区间仍含正常倍率 1 就保留不确定性，
**不凭单次首末轴读数指认具体级位**。

## 一键启动（Docker Compose，自动安装依赖并构建）

```bash
docker compose up --build
```

启动后访问：

| 页面 | 地址 |
| --- | --- |
| 单台选配 | **http://localhost:3000/** |
| 批量装配（2～3 台） | **http://localhost:3000/batch**（或 `/batch.html`） |
| 缺齿补货采购建议（2 台） | **http://localhost:3000/procure**（或 `/procure.html`） |
| 双档换速（固定一级 + 换装一级） | **http://localhost:3000/dual-speed**（或 `/dual-speed.html`） |
| 带载安全选配（扭矩校核） | **http://localhost:3000/torque**（或 `/torque.html`） |
| 轴位装配（定轴距 / 模数逐轴安装） | **http://localhost:3000/layout**（或 `/layout.html`） |
| 转速异常定位（转数观测 / 倍率定位） | **http://localhost:3000/diagnose**（或 `/diagnose.html`） |

后台运行可用 `docker compose up --build -d`，停止用 `docker compose down`。

> 依赖安装（`npm ci`）已写入镜像构建过程，首次启动自动完成，无需手动安装。

## 使用说明 — 单台选配

1. 填写**目标输出转速比**（输出轴 / 输入轴）：支持小数与分数，如 `0.0833`、`1/12`、`4`。
2. 填写**允许相对误差**：支持百分数 `5%` 或小数 `0.05`（二者等价，表示 5%）；填 `0%` 表示要求精确匹配。
3. 录入 2～12 枚齿轮：每行一个**唯一编号**（如 `G1`）与**正整数齿数**，可随时增删，或点“填入示例”。
4. 点击“开始选配”，结果区按排序规则列出达标方案，第一条标记为“最优”。
5. 若无任何达标组合，页面会明确提示无解，并建议放宽误差或增加齿轮。

## 使用说明 — 批量装配（2～3 台）

1. 在顶部导航进入 **批量装配**（`/batch`）。
2. 录入一份**共用齿轮清单**（2～12 枚，规则同单台页）。
3. 添加 **2～3 台装置**：每台填写名称（可空，默认“装置 1/2/3”）、各自的**目标速比**与**容差**。
4. 点击“开始批量装配”，系统对每台枚举**全部**达标配对（不受单台接口 300 条返回上限影响），
   按**占用齿轮集合**为每台保留最优候选，再求互不冲突的组合。
5. 结果区展示：
   - 汇总：**达标台数 / 总台数、总级数、相对误差之和**；
   - 每台装置的选中配对（级/主动轮/从动轮/本级速比、实际总速比与误差）或**未满足**状态
     （区分“本身无任何达标配对”与“配对被整批全局择优占用”）；
   - **未使用齿轮**清单（整批中未被任何装置占用的齿轮）。

### 批量择优规则

在“每枚齿轮整批至多使用一次”的约束下，组合按以下顺序择优，保证结果唯一确定：

1. **达标台数最多**；
2. 并列时**总级数最少**；
3. 再并列时**相对误差之和最小**（精确分数相加比较）；
4. 最后按**装置输入顺序**逐台决胜：同序号优先让排在前面的装置满足，
   其选中方案再按齿轮编号**自然序**（`G2` 排在 `G10` 之前）比较。

## 使用说明 — 缺齿补货（2 台）

1. 在顶部导航进入 **缺齿补货**（`/procure`）。
2. 录入 **2～8 枚现有库存齿轮**（编号唯一、正整数齿数）。
3. 录入 **1～4 枚可购实物齿轮**：每行填写唯一编号、齿数与**非负整数价格**；
   现有齿轮与可购齿轮编号互不重复，两类合计不超过 **12 枚**。
4. 填写固定 **2 台装置**各自的目标速比与容差（规则同前两个页面）。
5. 点击“生成采购建议”，系统在“现有 + 全部可购”的完整齿轮池上枚举两台的全部达标方案，
   再对可购齿轮的**每个子集**（含空集，共 ≤ 16 个）复用批量装配的完整达标分配，
   判断两台能否在齿轮不复用下同时装配。
6. 结果区展示：
   - **建议购买清单**（枚数与合计价格）与唯一决胜依据；
   - 两台装置各自的实际配对（级/主动轮/从动轮/本级速比、实际总速比与误差）；
   - **未使用齿轮**（标注“现有 / 已购未用”）。
7. **现有库存已可装配**时（空集可行）返回**空采购清单**并明确提示无需采购；
   **所有子集均无解**时明确提示，并指出哪一台即使买下全部可购齿轮也无任何达标配对。

### 采购建议决胜规则

在“两台均达标装配”的可购齿轮子集中，按以下顺序选出**唯一**建议：

1. **购买枚数最少**；
2. 并列时**购买总价最低**（价格均为非负整数，直接相加）；
3. 再并列时按购买齿轮的**编号自然序序列**决胜
   （逐枚比较编号，`P2` 排在 `P10` 之前；等价于子集编号排序后的字典序）。

子集内部两台的具体配对方案，则完全沿用**批量装配**的分配与择优规则
（总级数最少 → 相对误差之和最小 → 装置顺序与编号自然序）。

## 使用说明 — 双档换速

1. 在顶部导航进入 **双档换速**（`/dual-speed`）。
2. 录入 **4～12 枚共用齿轮**（编号唯一、正整数齿数；至少 4 枚：固定级 2 枚 + 换装级 2 枚）。
3. 填写固定 **2 个档位**各自的目标速比与容差（规则同其他页面；名称可空，默认“档位 1/2”）。
4. 点击“开始双档选配”，系统枚举**全部**“固定第一级 + 两档换装第二级”的达标组合
   （每档恰好两级、档内 4 枚齿轮不复用、两档换装级允许使用相同实物），按择优规则选出唯一方案。
5. 结果区展示：
   - **固定第一级**（两档共用的有向齿轮对，换档时保持不动）；
   - 两个档位各自的**换装第二级**、实际总速比与相对误差；
   - **换档需更换的轴位**：第二级主动轴 / 从动轴中实物不同的项（0～2 个），
     实物相同的轴位一并列出并标注“无需更换”。
6. 无任何达标组合时明确提示无解，并指出哪个档位在任意固定第一级下都不存在达标的换装组合。

### 双档择优规则

在全部达标候选（完整枚举，不截断）中按以下顺序选出**唯一**方案：

1. **需更换的轴位数量最少**：比较两档换装级的主动轴位与从动轴位，
   实物齿轮相同的轴位换档时无需拆装（0～2 个）；
2. 并列时**两档相对误差之和最小**（精确分数相加比较）；
3. 再并列时按（固定主动 → 固定从动 → 档位一换装主动 → 档位一换装从动 →
   档位二换装主动 → 档位二换装从动）的齿轮编号**自然序**序列决胜
   （`G2` 排在 `G10` 之前）。

## 使用说明 — 带载安全选配

1. 在顶部导航进入 **带载安全**（`/torque`）。
2. 目标参数沿用单台页：填写**目标输出转速比**与**允许相对误差**；
   另填写正整数**输入扭矩**（单位 N·m，1～10¹²）。
3. 录入 2～12 枚齿轮：每行填写唯一编号、正整数齿数与该枚齿轮的正整数
   **额定扭矩**（N·m，1～10¹²），或点“填入示例”。
4. 点击“开始带载选配”，系统先完整枚举全部速比达标的配对组（规则同单台），
   再对**每组配对的全部级次排列**（k 级即 k! 种顺序）逐级做无损传动扭矩校核：
   - 每级**主动轮**承受**该级输入扭矩**；
   - 每级**从动轮**承受 **输入扭矩 × 从动齿数 / 主动齿数**（齿数反比，可化为分数），
     该值即下一级输入扭矩；
   - 两轮承受值均不得超过各自额定扭矩。
5. 结果区先给出统计：**速比达标配对组数、共校核的级次顺序数、速比与载荷均达标方案总数**；
   每条方案表格逐级展示**主动轮 / 从动轮的承受扭矩（分数 + 小数）与额定扭矩**、
   本级输入扭矩与本级速比；承受值恰好等于额定值时标注“满载”。
6. **无解时明确区分两类原因**：
   - **速比无解**（`reason: "ratio"`）：任何组合的速比误差都不达标，未进入扭矩校核；
   - **全部超载**（`reason: "overload"`）：存在速比达标配对，但其**全部级次顺序**
     都至少有一枚齿轮承受扭矩超过额定值，提示中给出配对组数与校核的顺序总数。

### 为什么级次顺序必须分别校核

扭矩沿传动链逐级传递（从动轮承受值成为下一级输入），同一组有向配对仅级次顺序不同时，
各级主动/从动轮的**承受扭矩完全不同**：某些级序安全，另一些级序可能超载。
因此本页不能沿用单台搜索按主动轮编号归一化后的唯一级序，也不能以单台接口
截断后的前 300 条候选代替完整枚举——每组配对的 k! 种排列均独立校核，
每种通过校核的级序本身就是一条独立方案。

### 排序规则

全部达标方案（完整枚举，不截断候选）按与单台一致的顺序排序后，
仅展示前 300 条（`truncated: true` 表示已截断，但 `total` 为完整总数）：
**级数最少 → 速比相对误差最小 → 各级 (主动轮编号, 从动轮编号) 序列自然序**
（比较使用实际级次顺序；`G2` 排在 `G10` 之前）。

## 使用说明 — 轴位装配

1. 在顶部导航进入 **轴位装配**（`/layout`）。
2. 按 **输入轴 → 输出轴** 的顺序填写 **2～4 个轴心**：
   - 一维布置：每行只填 **X 整数坐标**（Y 留空视为 0），如 `0`、`60`、`90`；
   - 二维布置：X、Y 都填整数，如 `(0,0)`、`(3,4)`；
   - 各轴必须**互不重合、严格共线且沿同一方向依次排列**（提交时整数精确校验，
     不使用浮点）；可随时增删轴心（2～4 个）。
3. 填写统一正整数**模数 m**（1～100000），以及**目标输出速比 / 允许相对误差**
   （规则同其他页面；`0%` 表示要求精确匹配）。
4. 录入 **2～12 枚现有齿轮**（编号唯一、正整数齿数）；n 个轴共 n−1 级，
   至少需要 **2(n−1)** 枚齿轮（中间轴同轴固定的两轮为不同实物）。
5. 点击“开始轴位装配”，系统先由相邻轴坐标计算每级轴距 d 与啮合所需齿数和
   **2d / m**（必须为 ≥2 的整数，否则该级几何上无整数齿数解），再：
   - 穷举每级满足“主动齿数 + 从动齿数 = 2d/m”的全部**有向配对**；
   - 跨级组合（每枚齿轮全程只用一次，DFS 剪枝）；
   - 对每种完整装配以**精确分数**计算总速比 ∏(主动齿/从动齿) 与相对误差并校核容差。
6. 结果区展示：
   - **逐级几何核对表**（坐标差、轴距、需求齿数和、本级有向配对数）；
   - 达标方案总数与**最优方案**：逐级啮合配对表 + **逐轴安装明细**
     （首轴主动轮、末轴从动轮、中间轴同轴固定的前级从动轮/后级主动轮）与未使用齿轮。
7. **无解时明确区分两类原因**：
   - **无可啮合装配**（`reason: "meshing"`）：某级轴距非整数、2d 不能被模数整除、
     齿数和无齿轮对满足，或各级虽有配对但跨级无法做到齿轮不重复；
   - **可装配但速比不达标**（`reason: "ratio"`）：存在完整可啮合装配，
     但全部装配的速比误差均超出容差；页面附上**误差最小**的一种装配（标注“不达标”）。

### 轴位装配的择优规则

在全部满足全部轴距、齿轮不重复且速比达标的完整装配中按以下顺序选出**唯一**最优：

1. **相对误差最小**（精确分数比较）；
2. 并列时按各级 (主动轮编号, 从动轮编号) 序列做**编号自然序**决胜
   （逐对逐级比较；`G2` 排在 `G10` 之前）。

## 使用说明 — 转速异常定位

1. 在顶部导航进入 **转速异常定位**（`/diagnose`）。
2. 按 **输入轴 → 输出轴** 的顺序录入已装好的 **1～3 级**齿轮：每级填写
   **主动齿数 / 从动齿数**（正整数），系统据此逐级精确计算理论本级速比
   （主动/从动）与各轴相对输入轴的理论转速比。
3. 添加 **1～20 次观测**，每次观测填写：
   - 观测名称（可空，默认“观测 N”）；
   - 该次观测在**同一时段**记录的各轴读数：**轴号、转数、该读数的绝对误差**
     （可带小数，如 `366.67`；无误差填 `0`）。每次**至少记录输入轴（轴 1）
     与输出轴（轴 n+1）**，**中间轴允许缺少**；同一观测内**同一轴只能记录一次**。
     绝对误差必须**小于转数本身**（否则真实转数区间 [N−e, N+e] 覆盖零值，
     无法计算正的速比区间，提交时返回 400）。
4. 点击“开始异常定位”，系统：
   - 由齿数用精确分数算出每段轴的理论速比；
   - 对每次观测内**全部已记录轴对**（不限于相邻轴），把读数误差区间换算为
     实测速比区间 `[L, H]`：L = (N_b−e_b)/(N_a+e_a)、H = (N_b+e_b)/(N_a−e_a)；
   - 标记每个轴段是否与理论速比相符（理论值是否落在 [L,H] 内）；
   - 在“**至多一级**存在**跨观测恒定**倍率偏差 m”的假设下逐级计算：
     含该级的轴段要求 m ∈ [L/T, H/T]，跨全部观测取**交集**；
     **不含该级的轴段必须全部与理论相符（交叉核对）**。
5. 结果区先给出总体结论（四类之一），再列出**逐级倍率可行区间表**与
   **逐次观测的读数 / 轴段明细**：
   - **传动正常**（`normal`）：全部轴段区间覆盖理论值——即使某级确有偏差，
     其取值仍与正常倍率 m = 1 不可区分，按正常处理并保留该不确定性；
   - **可疑级位**（`suspect`）：恰好一级可行，给出该级与跨观测恒定倍率范围，
     并说明倍率整体在 1 的上方（实测偏快）还是下方（偏慢）；
   - **多个级位无法区分**（`ambiguous`）：多级均可单独解释全部观测；
     当各次观测都只有首末轴读数时，各级倍率区间必然完全相同，
     页面会明确提示**不能仅凭首末轴读数指认级位**，并建议补测中间轴；
   - **与单级恒定偏差假设不符**（`inconsistent`）：没有任何一级的恒定倍率区间
     能同时兼容全部观测（区间无交集或交叉核对失败），可能是多级异常、
     倍率随工况变化或误差被低估，并列出全部偏离理论值的轴段。

### 转速异常定位的判定要点

- 理论速比与区间换算全部使用 **BigInt 精确分数**（转数、误差支持十进制小数），
  无浮点误差；倍率区间端点同时以分数与小数返回。
- 只要某级可行区间仍**包含正常倍率 1**，就不判定该级异常（保留不确定性）；
  因此误差较大、区间较宽时结论倾向“传动正常”，这是保守且正确的行为。
- **单次观测只记录首末轴**时，任何一级都能解释整体倍率偏差，系统只给
  `ambiguous`；用含中间轴的观测（哪怕只补一个中间轴）即可逐级排除 / 确认。
- “恒定”是跨观测约束：同一级在不同观测中要求的 m 区间交集为空时，
  该级即被排除；所有级都被排除时给出 `inconsistent`。

## HTTP 接口

### `POST /api/search`（单台）

```json
{
  "target": "1/12",
  "tolerance": "5%",
  "gears": [
    { "id": "G1", "teeth": 10 },
    { "id": "G8", "teeth": 60 }
  ]
}
```

返回中 `total` 为达标方案总数，`results` 按级数/误差/编号排序后最多返回 300 条
（`truncated: true` 时表示已截断）；`total: 0` 即无解。

### `POST /api/batch`（批量装配）

```json
{
  "gears": [
    { "id": "G1", "teeth": 10 },
    { "id": "G8", "teeth": 60 }
  ],
  "devices": [
    { "name": "装置甲", "target": "1/12", "tolerance": "5%" },
    { "name": "装置乙", "target": "1/6", "tolerance": "5%" }
  ]
}
```

- `devices` 必须为 **2～3** 台；`name` 可省略（按顺序默认“装置 N”）。
- 返回：
  - `matchedCount` / `deviceCount`：达标台数 / 总台数；
  - `totalStages`、`errorSum`（+ `errorSumPercent`）：总级数与相对误差之和；
  - `devices[]`：逐台给出 `target`、`tolerance`、
    `totalMatches`（该台**全量**达标方案数，未截断）、
    `candidateCount`（按占用齿轮集合去重后的候选数）、
    `matched` 与 `solution`（结构同单台结果；未满足时为 `null`）；
  - `unusedGears`：未被任何装置占用的齿轮。
- 批量分配直接基于完整枚举（全量达标配对），**不会**只取 `/api/search` 截断后的前 300 条。

### `POST /api/procure`（缺齿补货采购建议）

```json
{
  "existingGears": [
    { "id": "G1", "teeth": 10 },
    { "id": "G2", "teeth": 60 }
  ],
  "buyableGears": [
    { "id": "P1", "teeth": 30, "price": 260 },
    { "id": "P2", "teeth": 48, "price": 80 }
  ],
  "devices": [
    { "name": "装置甲", "target": "1/6", "tolerance": "5%" },
    { "name": "装置乙", "target": "2/3", "tolerance": "5%" }
  ]
}
```

- `existingGears` 必须 **2～8** 枚；`buyableGears` 必须 **1～4** 枚；
  两类齿轮编号互不重复，合计 **≤ 12** 枚；`price` 为**非负整数**。
- `devices` 必须恰好 **2** 台（`name` 可省略，默认“装置 1/2”）。
- 有解时返回：
  - `feasible: true`；
  - `noPurchaseNeeded`：现有库存是否已足够（为 `true` 时采购清单为空）；
  - `purchaseCount` / `totalPrice`：建议购买枚数与合计价格；
  - `purchasedGears[]`：建议购买的齿轮（含 `teeth`、`price`、`used`）；
  - `subsetsChecked` / `feasibleSubsets`：枚举子集总数与其中可装配的子集数；
  - `totalStages`、`errorSum`（+ `errorSumPercent`）：两台实际方案的总级数与误差之和；
  - `devices[]`：逐台给出 `target`、`tolerance`、`hasMatchInPool`
    （在完整齿轮池上是否存在达标候选）与 `solution`（结构同单台结果）；
  - `unusedGears[]`：未被任何一台占用的可用齿轮，`origin` 为
    `existing`（现有）或 `purchased`（已购未用）。
- 所有子集均无解时返回 `feasible: false`、空采购清单、`message` 明确提示，
  并用各台 `hasMatchInPool` 指出瓶颈所在。
- 速比、容差与齿轮规则与 `/api/batch` 完全一致（1～3 级、齿轮不复用、精确分数判定）；
  每个子集都在完整达标候选上做分配，**不**受单台接口 300 条返回上限影响。

### `POST /api/dual-speed`（双档换速）

```json
{
  "gears": [
    { "id": "G1", "teeth": 10 },
    { "id": "G2", "teeth": 60 },
    { "id": "G3", "teeth": 20 },
    { "id": "G4", "teeth": 40 },
    { "id": "G5", "teeth": 30 }
  ],
  "speeds": [
    { "name": "档位一", "target": "1/12", "tolerance": "5%" },
    { "name": "档位二", "target": "1/9", "tolerance": "5%" }
  ]
}
```

- `gears` 必须 **4～12** 枚（规则同其他接口）；`speeds` 必须恰好 **2** 个档位
  （`name` 可省略，默认“档位 1/2”）。
- 每个档位均为**恰好两级**传动：第一级为两档共用的同一**有向齿轮对**（固定级），
  第二级为按档换装的有向齿轮对（换装级）；每档内 4 枚齿轮互不重复；
  两档互斥运行，因此两档换装级允许使用相同实物齿轮。
- 有解时返回：
  - `feasible: true`、`candidateCount`（完整达标组合总数，不截断）；
  - `fixedStage`：固定第一级（`drive` / `driven` / `stageRatio`）；
  - `speeds[]`：每档的 `solution`（`stages` 恒为 2；`pairs[0]` 为固定级、
    `pairs[1]` 为该档换装级，含实际总速比 `ratio` 与相对误差 `error` / `errorPercent`）；
  - `changeCount` / `changedPositions`：换档需更换的轴位数量与清单
    （`drive` = 第二级主动轴位，`driven` = 第二级从动轴位）；
  - `errorSum`（+ `errorSumPercent`）：两档相对误差之和。
- 无解时返回 `feasible: false` 与明确 `message`，并用各档 `hasCandidate`
  指出哪个档位在任意固定第一级下都不存在达标的换装组合。
- 速比、容差与齿轮校验规则与其他接口完全一致（精确分数判定）；
  择优基于**完整候选**，不受 `/api/search` 300 条返回上限影响。

### `POST /api/torque`（带载安全选配）

```json
{
  "target": "1/12",
  "tolerance": "5%",
  "inputTorque": 100,
  "gears": [
    { "id": "G1", "teeth": 10, "ratedTorque": 200 },
    { "id": "G5", "teeth": 40, "ratedTorque": 1000 }
  ]
}
```

- `inputTorque` 为**正整数**输入扭矩（1～10¹² N·m）；每枚齿轮除 `teeth` 外必须带
  正整数 `ratedTorque`（额定扭矩，1～10¹² N·m）；齿轮数量、编号与齿数规则同 `/api/search`。
- 先按单台规则完整枚举速比达标配对组（1～3 级、齿轮不复用、精确分数判定），
  再对每组配对的**全部 k! 种级次顺序**逐级校核：
  主动轮承受该级输入扭矩；从动轮承受 `输入扭矩 × 从动齿数 / 主动齿数`
  并作为下一级输入；两轮承受值均须 ≤ 各自额定值。
  完整候选一律参与校核，**不**使用 `/api/search` 的规范化级序去重，也**不**受 300 条截断影响。
- 有解（`feasible: true`、`reason: "ok"`）时返回：
  - `ratioMatchCount`：速比达标的配对组数；
  - `loadCandidatesChecked`：实际校核扭矩的级次顺序总数（含超载被淘汰者）；
  - `total` / `truncated` / `count`：速比与载荷均达标方案的完整总数、是否截断、本次返回条数；
  - `results[]`：按级数 → 误差 → 级次编号自然序排序的前 300 条；每条 `pairs[]` 逐级给出
    `inputTorque`（本级输入扭矩）与 `drive` / `driven`（编号、齿数、`ratedTorque`、
    承受扭矩 `torque`（分数 + 小数）、`atLimit`（是否恰好满载））、`stageRatio`。
- 无解（`feasible: false`）时区分：
  - `reason: "ratio"`：**速比无解**，无任何速比达标配对（`ratioMatchCount: 0`）；
  - `reason: "overload"`：**全部超载**，有速比达标配对但全部级次顺序均不满足额定约束
    （`ratioMatchCount > 0`、`total: 0`，`message` 说明校核顺序总数）。
- 所有扭矩比较以整数分数（BigInt）完成，无浮点误差；承受扭矩为分数时
  以约分分数 `num/den` 与小数同时返回（如 `10000/3 ≈ 333.3333333333`）。

### `POST /api/layout`（轴位装配）

```json
{
  "axes": [
    { "x": 0, "y": 0 },
    { "x": 60, "y": 0 },
    { "x": 90, "y": 0 }
  ],
  "module": 2,
  "target": "1/3",
  "tolerance": "5%",
  "gears": [
    { "id": "G1", "teeth": 10 },
    { "id": "G2", "teeth": 20 },
    { "id": "G3", "teeth": 24 },
    { "id": "G4", "teeth": 36 }
  ]
}
```

- `axes` 必须为 **2～4** 个沿一条直线依次排列的轴心；每个点可写单个整数
  （一维，Y 视为 0）或 `{ "x": 整数, "y": 整数 }`（Y 可省略）；相邻轴必须
  互不重合、方向共线且同向（提交参数非法时返回 **400** 与明确错误）。
- `module` 为各级统一的**正整数**模数（1～100000）；`gears` 规则同 `/api/search`
  （2～12 枚），但 n 个轴（n−1 级）至少需要 **2(n−1)** 枚，不足时返回 400。
- 每级啮合条件：**2×轴距 = 模数×(主动齿数+从动齿数)**；轴距由整数坐标算出
  （二维距离须为整数，即 Δx²+Δy² 须为完全平方数），需求齿数和 2d/m 必须为
  ≥2 的整数；系统穷举每级满足该齿数和的全部有向配对，再跨级组合
  （每枚齿轮全程只用一次），总速比与相对误差全部以精确分数（BigInt）校核。
- 有解（`feasible: true`、`reason: "ok"`）时返回：
  - `total`：达标完整装配总数；`assemblyCount`：满足全部轴距的完整装配总数；
  - `stages[]`：逐级几何信息（`dx`/`dy`/`distance`/`distanceSquared`、
    `requiredTeethSum`、`meshingPossible`、`candidateCount` 本级有向配对数）；
  - `best`：最优达标装配，含：
    - `ratio` / `error` / `errorPercent`：实际总速比（分数+小数）与相对误差；
    - `pairs[]`：逐级给出轴间（`fromAxis`/`toAxis`）、`axisDistance`、
      `requiredTeethSum`、主动轮 / 从动轮（编号、齿数）与 `stageRatio`；
    - `shafts[]`：**逐轴安装明细**，每轴给出坐标与 `mounts[]`
      （首轴 1 枚主动轮、末轴 1 枚从动轮；中间轴 2 枚，标注“前级从动轮 / 后级主动轮（同轴固定）”）；
    - `unusedGears[]`：未被使用的齿轮。
- 无解（`feasible: false`）时区分：
  - `reason: "meshing"`：**无可啮合装配**——某级几何上不存在整数齿数解
    （轴距非整数、2d 不被模数整除或齿数和 < 2，`stages[]` 中给出
    `meshingReason`），或每级虽有配对但跨级无法不重复组合；
  - `reason: "ratio"`：**可装配但速比不达标**——`assemblyCount > 0`
    但 `total: 0`；返回 `closest`（结构同 `best`）为误差最小的完整装配
    （并列时按编号自然序），仅供参考。
- 达标方案排序：**相对误差最小 → 各级 (主动轮编号, 从动轮编号) 编号自然序**。

### `POST /api/diagnose`（转速异常定位）

```json
{
  "stages": [
    { "driveTeeth": 20, "drivenTeeth": 40 },
    { "driveTeeth": 24, "drivenTeeth": 36 },
    { "driveTeeth": 18, "drivenTeeth": 54 }
  ],
  "observations": [
    {
      "name": "观测一（全轴同测）",
      "readings": [
        { "axis": 1, "revolutions": 3600, "error": 5 },
        { "axis": 2, "revolutions": 1800, "error": 4 },
        { "axis": 3, "revolutions": 1320, "error": 3 },
        { "axis": 4, "revolutions": 440, "error": 2 }
      ]
    },
    {
      "name": "观测二（缺第 3 轴）",
      "readings": [
        { "axis": 1, "revolutions": 3000, "error": 5 },
        { "axis": 2, "revolutions": 1500, "error": 4 },
        { "axis": 4, "revolutions": "366.67", "error": 2 }
      ]
    }
  ]
}
```

上例（第 2 级实测转速约为理论的 1.1 倍）返回 `verdict: "suspect"`、
`suspectStage: 2`，第 2 级跨两次观测的恒定倍率区间约为
`m ∈ [1.0960, 1.1040]`（区间整体在 1 上方，偏快），第 1、3 级分别因
交叉核对失败 / 倍率区间无交集被排除。

- `stages` 必须为 **1～3** 级；每级 `driveTeeth` / `drivenTeeth` 为
  **1～100000 的正整数**。
- `observations` 必须为 **1～20** 次；每次 `readings` 中：
  - `axis` 为 **1～(级数+1)** 的轴号，**同一观测内不得重复**（重复返回 400）；
  - 每次观测**必须同时含轴 1（输入轴）与末轴（输出轴）**，缺一返回 400；
    中间轴可缺；
  - `revolutions` 为该轴同一时段的**正转数**（数字或十进制字符串，
    非正数返回 400）；`error` 为该读数的**绝对误差**（非负，可填 `0`，
    负数返回 400）；**误差 ≥ 转数**时真实转数区间覆盖零值，返回 400。
- 返回：
  - `stages[]`：各级齿数与 `stageRatio`（分数 + 小数）；
    `shaftRatios[]`：各轴相对输入轴的理论转速比；
  - `observations[]`：每次的 `axes`、`readings[]`（转数 / 误差分数）
    与 `segments[]`——该次观测全部已记录轴对的实测速比区间
    `low`/`high`、`theory` 与 `normal`（区间是否覆盖理论值）；
  - `verdict`：`normal` / `suspect` / `ambiguous` / `inconsistent` 四选一；
    `normal` 为是否全部轴段相符的布尔值；
  - `candidates[]`：逐级给出含该级轴段的倍率交集 `factorLow` / `factorHigh`
    （分数 + 小数）、`intersectionNonEmpty`（交集是否非空）、
    `containsUnity`（区间是否含正常倍率 1）、`direction`
    （`above` / `below` / null）、`feasible`（交集非空且交叉核对通过）
    与 `crossCheckFailed[]`（不含该级却偏离理论的轴段清单，含观测序号与轴段）；
  - `feasibleStages[]` / `suspectStage`：可行级位列表与唯一可疑级
    （仅 `suspect` 时非空）；
  - `endAxesOnly`：是否每次观测都只记录了首末轴（为真且 `ambiguous` 时
    页面明确提示不可凭首末轴指认级位）；
  - `abnormalSegments[]`：全部偏离理论值的轴段清单；
  - `message`：面向页面的中文结论说明。

## 计算与排序规则

- 每级转速比 = 主动轮齿数 / 从动轮齿数；总速比 = 各级速比之积（全程约分分数）。
- 相对误差 = |实际速比 − 目标速比| / 目标速比，同样以分数比较，达标条件：相对误差 ≤ 允许值。
- “仅各级排列顺序不同”的同一配对方案只保留一条（按主动轮编号归一化）。
- 并列方案按各级 (主动轮编号, 从动轮编号) 序列做自然序比较（`G2` 排在 `G10` 之前）。
- 12 枚齿轮最坏情况枚举约 10 万量级方案，秒级完成。

### 带载安全选配的扭矩传递

- 第 1 级主动轮承受整机输入扭矩 T₀；
- 某级从动轮承受 T_从动 = 该级输入扭矩 × 从动齿数 / 主动齿数，
  并成为下一级输入扭矩（无损传动，忽略损耗）；
- 每个两轮的承受扭矩均须 ≤ 其额定扭矩；比较全部走整数分数不等式（BigInt），无浮点误差；
- 同一组配对的全部 k! 种级次顺序**分别校核**（不归一化、不截断候选），
  每种通过校核的级序都是一条独立方案；12 枚齿轮最坏情况需校核数十万种级序，仍为数秒级。

### 轴位装配的几何与枚举

- 第 i 级装在第 i、i+1 个轴心之间，安装距即轴距
  dᵢ = √((xᵢ₊₁−xᵢ)² + (yᵢ₊₁−yᵢ)²)；整数坐标下先判定距离平方为完全平方数，
  全程整数运算，无浮点误差；
- 啮合条件 **2dᵢ = m ×(主动齿数 + 从动齿数)** 要求 2dᵢ 能被模数 m 整除、
  齿数和 ≥ 2，否则该级几何上无整数齿数解（“无可啮合装配”）；
- 每级枚举满足齿数和的全部有向配对（同一对齿轮两个朝向都算），跨级 DFS
  组合并即时剔除已用齿轮；中间轴上的前级从动轮与后级主动轮是**同轴固定的两枚实物**；
- 总速比 = ∏ 主动齿 / 从动齿（BigInt 连乘后统一约分），相对误差与容差判定
  全部走整数乘法不等式；4 轴最多 3 级，穷举量很小。

### 转速异常定位的区间换算与逐级判定

- 理论速比由齿数精确给出：第 k 级 Tₖ = 主动齿/从动齿；轴 a → 轴 b 的理论
  速比 T = ∏(a≤k<b) Tₖ（BigInt 累积分率，无浮点误差）；
- 读数 N ± 绝对误差 e 表示真实转数 ∈ [N−e, N+e]（要求 N > e ≥ 0）；
  轴 a → 轴 b 的实测速比区间为
  **L = (N_b−e_b)/(N_a+e_a)，H = (N_b+e_b)/(N_a−e_a)**，端点全为精确分数；
- 轴段与理论相符 ⇔ L ≤ T ≤ H（分数比较）；
- 单级恒定倍率假设：至多一级 k 满足“实测 = m × 理论”且 m 跨观测恒定。
  对每次观测内**全部已记录轴对**：
  - 轴段 a→b **含**第 k 级（a ≤ k < b）时给出约束 m ∈ [L/T, H/T]，
    跨全部观测取**交集**作为该级可行倍率区间；
  - 轴段**不含**第 k 级时必须与理论相符，否则该级**交叉核对失败**；
  - 交集非空且交叉核对全部通过 ⇔ 该级可行；
- 全部轴段相符 → `normal`（含 1 的区间不指认任何级）；恰有一级可行 →
  `suspect`（给倍率范围与偏快 / 偏慢方向）；多级可行 → `ambiguous`
  （仅首末轴读数时各级区间完全相同，绝不强行指认）；无级可行 →
  `inconsistent`（与单级恒定偏差假设不符）。
